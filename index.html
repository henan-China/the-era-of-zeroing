10 · Videos

分镜视频（预览与成片）

两种接入方式，任选其一或并用：A 本地视频（≤100MB，推进 assets/ 后页面直接播放）；B 外链视频（>100MB 或已在平台发布，填链接即可）。在 content.js 的 VIDEOS 里添加条目。

▶ 怎么把视频放进来

  1. 本地视频（≤100MB）：把文件发给管理员（或放到仓库 assets/），并在 content.js 的 VIDEOS 加一条 { ep, title, file: "文件名.mp4" }；页面用播放器直接观看
  2. 外链视频（>100MB / 平台成片）：先发布到 B 站、抖音等平台，复制链接，在 VIDEOS 加一条 { ep, title, ext: "https://…" }；页面显示卡片，点击跳转平台观看
  3. 一条视频可以同时写 file 和 ext：页面既播放本地预览，也给出平台成片链接
